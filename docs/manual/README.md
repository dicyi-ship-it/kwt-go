# Dokumentasi lengkap Mina Go

Panduan terbaru 6 November 2026 terdiri dari dua bab User dan Admin, dengan
31 screenshot baru yang diambil memakai Playwright Chromium dari kode terbaru
dan salinan data aktif. Semua gambar ditampilkan utuh tanpa crop.

- [Panduan User dan Admin Word](Panduan%20User%20dan%20Admin%20Mina%20Go.docx)
- [Panduan User dan Admin Markdown](Panduan%20User%20dan%20Admin%20Mina%20Go.md)
- [Screenshot terbaru](screenshots-current/manifest.json)

Dokumen di bawah ini merupakan arsip versi sebelumnya.

Panduan warga, pengelola, dan operasional MySQL dilengkapi 34 screenshot asli
dari Playwright Chromium. Setiap screenshot tampil utuh sebagai satu gambar
dalam DOCX tanpa dipotong. Ukuran halaman disesuaikan dengan panjang gambar.

- [Dokumen Word](Panduan%20Lengkap%20Mina%20Go.docx)
- [Panduan Markdown](Panduan%20Lengkap%20Mina%20Go.md)
- [Screenshot asli](screenshots/)
- [Daftar screenshot dan alamat halaman](screenshots/manifest.json)

Gambar diambil dari database MySQL dokumentasi terpisah menggunakan akun
dokumentasi. Nama pengurus dan nomor kontak pada gambar merupakan data contoh.
Alamat `localhost:4176` hanya digunakan selama pengambilan screenshot; alamat
lokal normal aplikasi adalah `http://localhost:4173`.

Jangan mengunggah folder `.local` atau database dokumentasi ke hosting publik.
